# Repository audit and implementation plan

The initial checkout contained only .git. There were no application files, dependencies, routes, assets, or components to preserve or remove.

## Architecture

Next.js App Router, TypeScript and Tailwind CSS. Server-rendered pages and statically generated topic pages; client JavaScript only for navigation and contact interactions. Self-hosted local fonts, local illustrative industry photography and Next Image. Standalone output for Linux/Hetzner deployment.

## Design

Editorial ivory and charcoal surfaces, forest green, restrained bronze, Manrope with Newsreader editorial accents. Fine rules, generous space, numbered indexes, a connected data diagram, and selective tactile buttons. Industrial imagery is illustrative, never a claim of a KINT project.

## First phase

Shared navigation/footer; home; about; industries and four sector pages; solutions and seven service pages; KINT Intelligence with six developing areas; insights and three original explanatory articles; contact and privacy. Careers, team profiles and case studies stay out of published navigation until verified content exists. Capability examples describe possible work, never completed projects.

## Release gates

Confirm corporate details, copy, image suitability/rights and article approval. Set live enquiry delivery and Turnstile; verify an end-to-end enquiry against the real receiver. Review privacy wording against chosen receiver/retention policy. Validate production domain and HTTPS reverse proxy. Measure Lighthouse on the deployed production site before asserting scores. No live deployment is part of this local first implementation.
